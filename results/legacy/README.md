# Legacy results

These files come from earlier model versions (pre-Injection-Aware MPNet) and
are kept for provenance only. Numbers in the paper come from:

- `results/injection_aware_mpnet_evaluation.json` (per-dataset MPNet metrics)
- `results/latest_benchmark_results.txt` (headline summary)
- `results/statistical_analysis.json` (confidence intervals)

Do not cite anything in this directory in the paper.
